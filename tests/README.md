# Тесты управления поставщиками и документами

## Запуск тестов

### Все тесты
```bash
python -m pytest tests/test_supplier_documents.py -v
```

### Конкретный тестовый класс
```bash
python -m pytest tests/test_supplier_documents.py::TestDocumentStatuses -v
```

### Конкретный тест
```bash
python -m pytest tests/test_supplier_documents.py::TestDocumentStatuses::test_approve_document_transition -v
```

## Структура тестов

### TestDocumentStatuses
- Тестирование основных статусов документов: на проверке, одобрен, отклонен
- Валидация переходов между статусами
- Проверка временных меток и причин отклонения

### TestDocumentValidation
- Валидация типов документов
- Проверка путей к файлам
- Обработка пустых файлов

### TestSupplierDocumentManagement
- Управление несколькими документами одного поставщика
- Статистика по документам поставщика

### TestDocumentStatusTransitions
- Сложные переходы между статусами
- Полный жизненный цикл документа
