Tender Document Checker
📌 Название проекта
Tender Document Checker (AI-ассистент по проверке тендерной документации)

🎯 Цель проекта
Автоматизировать проверку тендерной документации, спецификаций, договоров и связанных документов, поступающих от заказчиков, на соответствие внутренним стандартам компании. Повысить скорость отклика на тендеры и снизить риски несоответствий.

💼 Контекст и бизнес-потребность
Ежедневно в компанию поступают тендерные документы в формате PDF, DOCX.

Менеджеры вручную читают и проверяют каждый документ по десяткам критериев.

Ошибки в проверке или упущенные условия могут привести к потере контракта или штрафам.

Требуется решение, которое:

автоматически анализирует документацию,

выявляет несоответствия,

сохраняет историю проверок,

создаёт задачи в Bitrix24,

генерирует отчёты и отправляет их по email.

✅ Цели проекта
№	Цель	Результат
1	Ускорить проверку тендерных документов	Сокращение времени анализа на 80%

🏗️ Архитектура и модули
Язык: Python 3.11
Модули:

Модуль	Назначение

chunker.py	Разделение документа на логические блоки

emailer.py	Отправка отчёта по email

streamlit_ui.py	Интерфейс для загрузки и проверки документов
main.py	FastAPI endpoint для CI/CD-интеграции
tests/	Тесты на Pytest для ключевых модулей

🧪 Сценарии использования
📁 Сценарий 1: Проверка одного документа
Менеджер загружает файл на Streamlit-интерфейсе.

Модель извлекает текст, разбивает по разделам.

GPT сравнивает содержимое с YAML-стандартом.

Генерируется PDF + email + задача в Bitrix24.

🗂️ Сценарий 2: Пакетная обработка
Загружается несколько документов.

Система проверяет каждый документ.

Итоговые отчёты и задачи формируются автоматически.

🛰️ Сценарий 3: Webhook-интеграция Bitrix24
Bitrix отправляет событие по webhook.

FastAPI принимает его и создаёт комментарий.

При необходимости запускается проверка документации.
